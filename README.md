# Murmur-updates
Murmur Mac auto-update feed (appcast + DMGs). Source lives in private Murmur.

## X promo drafts

Publishing a Release runs `.github/workflows/x-social-draft.yml`, which creates an X **draft** in [King-Lollipop-Studio](https://github.com/mrkinglollipop/King-Lollipop-Studio). Requires Actions secret `STUDIO_PUSH_TOKEN` (PAT with `contents:write` on that studio repo). No X API keys here.
